# Народный бенчмарк

Открытый сайт, где любой может проверить свой процессор прямо в браузере и сравнить его с процессорами
других посетителей. Учебный проект.

Тесты выполняются **в браузере посетителя** (JavaScript, Web Workers) — нагружается его процессор, а не сервер.
Сервер только проверяет присланные цифры, пересчитывает очки и хранит результаты для общего топа.

Нагрузка начинается **только с разрешения**: после «Начать» сайт показывает, что узнал об устройстве, и спрашивает
«Можно нагрузить процессор?» — тест стартует лишь по кнопке «Разрешить и начать». Даже ссылка с `?start=1` только
открывает этот вопрос.

## Что показывает сайт

| | Откуда берётся |
|---|---|
| Устройство | Телефон, планшет, ноутбук, настольный ПК или Mac — по строке браузера, батарее, сенсорному экрану и подписи видеокарты («Laptop GPU») |
| Модель процессора | Браузер её не сообщает (защита приватности). Сайт угадывает по косвенным признакам (`bench/static/bench/js/guess.js`): у телефона — по графике (Adreno бывает только в Snapdragon, Xclipse — только в Exynos, Mali-G57 MC2 — в Helio G99 и Dimensity 6xxx…) и модели телефона (Samsung, Pixel); у iPhone — по размеру экрана; у компьютера — по коду встроенной графики Intel/AMD и числу потоков. Если признаков нет (у ПК видна только дискретная видеокарта), сайт честно пишет «модель не видна браузеру» и предлагает похожие — выбор запоминается |
| Ядра, частоты, кэш, **TDP (энергопотребление)**, год, техпроцесс | Справочник на ~400 процессоров: Intel, AMD, Apple M и Snapdragon X для компьютеров; Snapdragon, MediaTek, Exynos, Tensor, Unisoc, Kirin и Apple A для телефонов (`bench/engine/cpus.py`). TDP телефонных чипов производители не публикуют |
| Очки на одном ядре и на всех ядрах | 7 тестов: целые числа, дробные, сортировка, сжатие, шифрование, данные (JSON), память |
| **Частота, ГГц** (оценка) | Цепочка зависимых операций, каждая занимает 1 такт: операций в секунду ≈ тактов в секунду. Проверено на Ryzen 7 6800H — совпало со счётчиками Windows с точностью 2–4 % |
| **FPS** | Игровая сцена: стая из 10 000 объектов, каждый ищет соседей (как боты и частицы в играх), 1 поток |
| Нагрев | Марафон 20 с на всех потоках: насколько падает скорость, и частота до и после |
| Эффективность | Очки «все ядра» на ватт паспортного TDP |
| Место в топе, «быстрее X % замеров» | Сравнение со всеми замерами на сайте |
| **Не ослаб ли процессор** | Сравнение с такими же моделями у других посетителей, частота против паспортной турбо-частоты, нагрев, питание от батареи, прошлые замеры этого же браузера |

Сам кристалл процессора за годы почти не изнашивается — слабеют охлаждение (пыль, высохшая термопаста)
и настройки питания. Именно это и проверяет блок «Не ослаб ли процессор».

Очки: 1000 = одно ядро AMD Ryzen 7 6800H в Edge.

## Разделы

| Адрес | Что там |
|---|---|
| `/` | Тест: что определил браузер, выбор процессора, запуск, ход теста |
| `/r/<id>/` | Результат: паспорт, главные цифры, «не ослаб ли», сильные стороны, графики |
| `/top/` | Топ процессоров или всех замеров; сортировка по всем ядрам, одному ядру, FPS, очкам на ватт |
| `/admin/` | Удаление мусора из топа (только администратор) |

## Запуск у себя (Windows)

Дважды щёлкните `run.bat` — откроется http://localhost:8765/. Локально данные хранятся в SQLite.

Вручную:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install "Django>=5.2,<6.0" dj-database-url whitenoise
python manage.py migrate
python manage.py runserver 8765
```

Тесты: `python manage.py test bench`

## Публикация: GitHub → Neon → Render

Бесплатный Render стирает диск при каждом перезапуске (а засыпает он после 15 минут без посетителей),
поэтому замеры хранятся во внешней бесплатной базе Postgres на Neon.

1. **GitHub.** Залейте проект в репозиторий (`git push`).
2. **База Neon.** Зарегистрируйтесь на [neon.tech](https://neon.tech) (можно через GitHub) → *Create project* →
   скопируйте *Connection string* вида `postgresql://user:pass@ep-….neon.tech/neondb?sslmode=require`.
3. **Render.** [dashboard.render.com](https://dashboard.render.com) → *New* → *Blueprint* → выберите репозиторий.
   Render прочитает `render.yaml` и спросит `DATABASE_URL` — вставьте строку из Neon. `SECRET_KEY` он создаст сам.
   Вместо Blueprint можно создать *Web Service* вручную: Build Command `bash build.sh`,
   Start Command `gunicorn narod.wsgi:application`, переменные `DATABASE_URL`, `SECRET_KEY`, `PYTHON_VERSION=3.12.8`.
4. Через 2–3 минуты сайт откроется по адресу вида `https://narod-bench.onrender.com`. Каждый `git push`
   в репозиторий обновляет сайт сам.
5. *Необязательно:* чтобы удалять мусор из топа, добавьте в Render переменные `DJANGO_SUPERUSER_USERNAME`,
   `DJANGO_SUPERUSER_PASSWORD`, `DJANGO_SUPERUSER_EMAIL` и сделайте *Manual Deploy* — появится вход в `/admin/`.

Первое открытие после простоя занимает 30–60 секунд: бесплатный Render «просыпается».

## Защита топа

- Очки пересчитывает сервер по присланным скоростям; невозможные результаты (один поток быстрее 8 эталонных ядер,
  ускорение больше числа потоков) отклоняются.
- Не больше 8 сохранений за 15 минут с одного адреса. Сам IP не хранится.
- Публичной кнопки «удалить» нет — только через `/admin/`.

## Структура

```
NarodBench/
├── narod/settings.py            настройки (локально — SQLite, на Render — из переменных окружения)
├── bench/
│   ├── static/bench/js/
│   │   ├── worker.js            тесты, частота и игровая сцена — выполняются в браузере, в отдельных потоках
│   │   ├── guess.js             угадывание устройства и процессора (без страницы — можно проверить отдельно)
│   │   ├── bench.js             разрешение на нагрузку, запуск теста, отправка результата
│   │   └── charts.js            графики масштабирования и марафона
│   ├── engine/
│   │   ├── cpus.py              справочник процессоров, правила по графике и по модели телефона
│   │   ├── meta.py              описание тестов и эталон очков
│   │   └── analysis.py          топ, проценты, сильные стороны, «не ослаб ли процессор»
│   ├── payload.py               проверка результата от браузера, пересчёт очков
│   ├── templates/bench/         home, detail, top
│   ├── models.py                Result — сохранённые замеры
│   └── tests.py
├── build.sh, render.yaml        сборка и запуск на Render
└── run.bat                      запуск у себя
```

## Ограничения

- Справочник учебный и может содержать неточности; модели, которых в нём нет, можно вписать вручную — тогда паспорта не будет.
- Частота — оценка. Свёрнутая вкладка, режим экономии энергии и работа от батареи занижают все цифры.
- Разные браузеры выполняют JavaScript с разной скоростью: результаты Firefox и Safari могут отличаться от Chrome и Edge.
- Если браузер видит только дискретную видеокарту (игровые ПК и ноутбуки), модель процессора не видна — её придётся выбрать один раз из похожих.
- У телефонов с одинаковой графикой (например, Helio G99 и Dimensity 6100+ — обе Mali-G57 MC2) сайт показывает самый вероятный вариант с пометкой «примерно»; точнее — если браузер сообщает модель телефона (Chrome, Samsung Internet).
- iPhone: Safari скрывает и графику, и модель — чип угадывается по размеру экрана, тоже «примерно».
